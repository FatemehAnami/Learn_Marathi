# learn_marathi

**Learn Marathi** is a language-learning application focused on making Marathi learning simple, interactive, and beginner-friendly. This project was developed with significant assistance from AI coding and development tools, particularly Claude and ChatGPT.

The application organizes learning into:
    - Units
        - Lessons
            - vocabularies
            - examples
            - reviews
    Each unit contains several lessons followed by a **Unit Review** that revises the vocabulary learned throughout that unit.

🧠 Interactive Exercises

    The application currently supports several question types:

    🔤 Multiple choice
    🎧 Listening
    🔗 Match words
    📝 Choose the correct sentence
    ✍️ Fill in the blank
    🧩 Build the sentence

🔄 Unit Review

    After completing the lessons in a unit, the application creates a review lesson containing the vocabulary from the unit. 
    The review is designed to 
        - Use a fixed number of questions
        - Avoid repeating the same word
        - Review vocabulary from the entire unit
        - Test the learner using different question types

❤️ Hearts System
    Learners have a limited number of hearts. Incorrect answers can reduce the number of available hearts.

⭐ XP System

    Correct learning activity contributes to the learner's XP.

🔥 Streak

    The application keeps track of practice streaks using local storage.

🔓 Lesson & Unit Progress

    Units and Lessons unlock progressively.

    For example:

    Lesson 1 ✅
        ↓
    Lesson 2 🔓
        ↓
    Lesson 3 🔒

    Each Lesson unlock it previous lesson finished sucsesfuly. 

🛠️ Technology

    This project is built with:

    - Flutter
    - Dart
    - Material Design
    - SharedPreferences
    - JSON-based lesson content
    - Text to Speech for audio part

🚀 Getting Started
    Requirements
    - Flutter SDK
    - Dart SDK
    - Android Studio or VS Code
    - Android/iOS development environment
